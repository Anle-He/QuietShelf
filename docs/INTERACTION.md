# 交互流程

## 主界面

主界面是双栏资料库。左侧保留全部/书籍/影视筛选、搜索框、“添加”按钮和作品列表；每部作品只出现一次。选择作品后，右侧原地显示状态、阅读或观看次数、最近日期、综合分、当前一次和完整历史，避免层层弹窗。

## 添加作品

1. 点击“添加作品”。
2. 选择书籍或影视，输入标题。
3. 添加后默认为想读 / 想看，再从作品详情开始一次体验。

标题与类别相同的作品已存在时，应用提示打开已有作品或明确创建同名作品，不自动合并。

## 开始、补记与完成

选择作品后，在右侧选择“开始阅读 / 开始观看”。开始时只填写开始日期，不要求评分。进行中的作品显示“记一下”和“完成本次”：

- “记一下”记录某一天新增的分钟数或集数，并可附一段随手想法；它始终更新当前体验，不会新增一次阅读或观看。选择按集数时，可同时填写作品总集数，后续显示“已看 x / y 集”并自动沿用该总数。
- “完成本次”填写结束日期、最终四维评分和总结；结束日期不能早于开始日期。

完成后，这一次才进入历次完成、计入阅读或观看次数；评分完整时才进入作品综合分。随后主按钮变为“再读一次 / 再看一次”。

同一天开始和结束时只显示一个日期，跨日显示完整范围，进行中显示“始于”。旧记录的完成日期迁移为结束日期，开始日期保持为空；没有起止日期的旧空白记录不显示、不计数，也不会被自动删除。

## 搜索与回顾

搜索在输入时即时生效，只匹配用户输入的标题。类别筛选与搜索可以组合，清空搜索并选择“全部”即可回到完整作品库。时间线和日历只作为未来的次级回顾视图。

## 编辑与删除

- 当前一次中的每条中途记录可单独编辑或删除，累计进度随即重算。
- “放弃本次”删除当前体验及其中途记录，但保留作品和历次完成。
- 已完成体验可编辑日期、评分和总结，也可整次删除；完成次数和综合评分随即重算。
- 删除作品会级联删除全部体验与中途记录，执行前必须明确确认。

删除不可撤销，因此所有删除入口都显示具体影响范围并要求确认。
