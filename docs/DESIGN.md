# 界面方向

## 借鉴

- [已阅](https://norcy.xyz/iread/)：借鉴书籍与影视共用入口、“想看 / 在看 / 已看”的状态层级和轻量进度记录；不引入封面瀑布流、海报分享、会员与多端同步。
- [Letterboxd](https://letterboxd.com/about/faq/)：借鉴“作品记录”和“某次观看日志”分离的思路；同一作品的多次阅读或观看作为独立体验保存，并在作品详情中完整回顾。
- [Bookmory](https://bookmory.net/)：借鉴安静的阅读日志视觉；不引入计时、连续打卡、目标和 OCR。

## 开源实现参照

- [Openreads](https://github.com/mateusz-bak/openreads)：参照本地优先、隐私优先的产品边界和显式数据迁移；不采用把多次阅读压进单一序列化字段的做法。
- [LibrisLog](https://github.com/codebude/librislog)：参照可追加、可编辑、可删除的阅读进度时间线。
- [Yamtrack](https://github.com/FuzzyGrim/Yamtrack)：参照把同一媒体的多次体验拆成独立实例，而不是只维护一个“重看次数”。
- [WPF UI](https://github.com/lepoco/wpfui)：使用其 FluentWindow、标题栏、控件主题和 Windows 11 背景能力，保留 Windows 桌面应用应有的窗口行为。

## 当前视觉系统

- 暖白页面、白色卡片、深森林绿主操作，减少纯黑白界面的冷硬感。
- 首页采用双栏资料库：左侧搜索和选择作品，右侧原地展示作品详情，不再为普通浏览反复打开窗口。
- 多张封面在详情页以轻微错位和旋转形成照片堆；左侧只使用主封面，避免版本信息挤占列表。
- 右侧按“作品概览 → 当前一次 → 每日进度 → 历次完成”形成单一纵向路径；综合分、完成次数和累计进度保持在首屏。
- 新增、编辑等短任务保留为模态窗口，并统一使用 Fluent 控件、清晰的必填状态和可滚动表单。
- 添加作品只处理稳定信息；开始时只选日期，中途只记进度，结束时才填写四维评分与总结。
- 图标将打开的书页与胶片孔合成一个符号，保持两色、无文字，并针对 Windows 小尺寸输出多级 `.ico`。

## 暂不采用

- 封面瀑布流、推荐横幅和内容详情资料库
- 底部多标签导航与独立目标仪表盘
- 用成就、连续天数或通知推动使用
