# 迭代顺序

## 已完成：本地记录闭环

- Windows 桌面应用外壳和单页资料库界面
- SQLite 自动初始化、迁移与恢复副本
- 作品搜索、类别筛选、作者与多封面管理
- 同一作品的多次阅读或观看历史
- 进行中的体验和按日期记录的时长或集数进度
- StoryLand 四维评分、单次 Rank 和综合 Rank
- 仓储层自动化测试和发布产物工作流
- framework-dependent 的 win-x64 多文件发布包与安装程序

## 下一阶段：可靠性与可用性

- 键盘操作与基础无障碍检查
- 大型作品库的查询、列表虚拟化和响应性验证
- 安装、启动、升级、卸载和现有数据库迁移验收

## 后续阶段：安全回顾

- JSON 导出
- 导入前预览、冲突处理和可回滚备份
- 本年完成数、书籍数量和影视数量等扩展统计

每个阶段完成验证后再决定下一步。外部元数据和云服务不进入默认路线。
