# 迭代顺序

## M0：可运行骨架（当前）

- 应用外壳和克制的单页界面
- SQLite 自动初始化
- 作品库、标题搜索和类别筛选
- 同一作品的多次阅读或观看历史
- 进行中的一次体验、按时长或集数记录的每日进度
- StoryLand 四维评分、单次 Rank 和综合 Rank
- Windows 应用图标与自包含发布包
- 空状态和输入校验

## M1：完成记录闭环

- 状态筛选
- 键盘操作与基础无障碍检查
- 仓储层自动化测试

## M2：安全回顾

- JSON 导出、导入前预览和可回滚备份
- 三项轻量统计
- 单文件或自包含发布包

每个里程碑结束后再决定下一步；封面、外部元数据和云服务不进入默认路线。
