# 产品边界

## 一句话定位

用最低操作成本记录“我正在读或看什么、每天推进了多少、完成后感觉如何”的本地 Windows 小工具。

## 设计原则

1. **记录先于整理**：标题和类别足以保存，其余字段均可跳过。
2. **事实先于补全**：只保存用户输入，不臆造作者、封面、评分或短评。
3. **作品先于记录**：首页以书籍或影视作品为单位；历次阅读和观看属于作品内部。
4. **本地先于服务**：无需注册、联网或订阅，数据由用户掌控。
5. **渐进披露**：常用操作直接可见，低频能力不占据主界面。

## 第一版包含

- 新增、编辑、删除书籍或影视作品
- 为同一作品追加多次阅读或观看记录
- 在进行中的一次体验里按日期记录时长或集数
- 按主标题或副标题搜索，按类别与状态筛选
- 轻量统计：总数、本年完成数、书籍/影视数量
- 导出与导入本地备份

## 第一版不包含

- 账号、云同步、多设备协作
- 动态、关注、评论、排行榜或推荐
- 自动抓取封面、ISBN、演员、导演等外部资料
- 复杂标签树、书架管理、借阅管理
- 单集标题、季/集资料库、后台计时器、目标打卡和提醒

## 作品

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 标题 | 是 | 用户输入的作品名 |
| 副标题 | 否 | 详情页展示的补充标题，不占用左侧列表空间 |
| 类别 | 是 | 书籍 / 影视 |
| 当前状态 | 否 | 想读想看 / 进行中 / 已读已看 |

## 每次阅读或观看

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 开始日期 | 是 | 开始阅读或观看的日期；创建后进入进行中 |
| 结束日期 | 完成时是 | 完成本次时默认当天；不得早于开始日期 |
| Allure | 否 | 1–5 分，综合分中权重为 1.5 |
| Immersion | 否 | 1–5 分 |
| Rationality | 否 | 1–5 分 |
| Illumination | 否 | 1–5 分 |
| 总结 | 否 | 完成本次时填写的一段自由文本 |

## 每日进度

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 日期 | 是 | 不得早于本次开始日期 |
| 方式 | 是 | 时长；影视还可选择集数 |
| 数量 | 是 | 本次实际增加的分钟数或集数 |
| 随手记 | 否 | 当天的一段简短想法，不参与最终评分 |

只有一次体验完成后才允许留下最终评分。单次四项全部填写后，应用只读显示 `Rank = (Allure × 1.5 + Immersion + Rationality + Illumination) ÷ 5`。作品综合分是所有“已完成且评分完整”的单次 Rank 平均值，只在最终结果保留一位小数，并以 `x.x / 3.9 · N次评分` 呈现。中途记录、未完成体验和评分不完整的体验都不参与计算。

## 第一版完成标准

- 从打开新增窗口到加入一部只有标题的作品，不超过三个明确动作。
- 同一作品在首页只出现一次，详情可追加任意多次阅读或观看。
- 同一作品最多有一次进行中的体验；中途补记不会产生重复体验。
- 断网时全部核心能力可用。
- 退出并重新打开后记录不丢失。
- 没有填写的信息保持为空，不用占位内容伪装完整。
